## Ce que dit le document, utile pour l'audit

- Environ **43 000 cartes** (≈ 42 800 annoncées dans la recherche).
- Sources de rédaction déclarées : **le collège et LiSA, pour chaque item**.
  Les éditions des collèges utilisées **ne sont pas précisées** : point à
  vérifier carte par carte (date de création/modification des notes).
- Organisation : un sous-paquet par matière, ex. `Deck EDN - MEA::CARDIOLOGIE`.
  Un paquet ACE (erreurs personnelles) et un deck LCA en plus.
- Tag **`TOUR-doublon`** : marque les notes redondantes (même verso partagé) ;
  rien n'est supprimé. Deck allégé ≈ 26 800 cartes :
  `deck:"Deck EDN - MEA" -tag:TOUR-doublon`.
  → Pour l'audit de couverture, **compter aussi les notes taguées** : une note
  `TOUR-doublon` couvre bien la connaissance.
- Format des cartes : question générale + sous-questions, réponse longue avec
  extrait de cours ; nuances en gris italique ; tableaux comparatifs.
  → Une même note couvre souvent plusieurs objectifs (cohérent avec la règle
  « ne jamais supprimer pour rang C »).
- Installation : Anki ≥ 25.07, add-ons de l'auteur à installer **avant**
  l'import (ils ne modifient que l'affichage, sauf le « Propagateur » qui
  recopie une correction de tableau vers les cartes sœurs après accord).
