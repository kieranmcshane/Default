# Règle de périmètre — rangs A/B dans chaque collège

Décision utilisateur initiale pour la pneumologie et la neurologie : **ne contrôler et mettre à jour que les connaissances A/B ; ne pas compter le C et ne pas supprimer les cartes correspondantes.** Les règles de `main` étendent cette politique A/B à tout collège ajouté.

| Situation de la connaissance dans la source concernée | Traitement |
| --- | --- |
| A ou B, justifié dans la source | Inclus dans les objectifs attendus et le contrôle de contenu |
| C, justifié dans la source | Conservé comme hors périmètre, exclu des comptes de couverture et de conformité |
| Rang absent, ambigu ou sans preuve | À clarifier ; bloque la validation complète |
| Même note, C dans un collège mais A/B dans un autre | Évaluations séparées ; note conservée et contrôlée pour sa partie A/B |
| Note contenant à la fois A/B et C | Vérifier la partie A/B, conserver l’ensemble de la note |

Le rang est un attribut de l’objectif **dans une source et une édition**, pas du chapitre entier ni de la note Anki. Les 22 entrées CEP et 29 chapitres CEN fournis ne permettent pas de déduire les rangs des connaissances qu’ils contiennent. Aucun classement clinique réel n’a été inventé.

Les anciennes sauvegardes restent lisibles. Une ancienne validation de ces collèges n’est pas réutilisée comme validation A/B sans classification explicite. Depuis la lecture des consignes de main, la règle générale A/B est appliquée par défaut à tous les collèges (`edn-ab-v2`), avec une signature distincte par source/spécialité. Les classements et validations restent indépendants entre collèges.

La lecture seule des paquets Anki reste inchangée. Les sélections, suppressions d’objectifs de travail ou associations dans le registre ne suppriment aucune note dans Anki.

Si un objectif de travail mélange plusieurs rangs, le décomposer dans le registre en plusieurs connaissances évaluables. Les liens peuvent pointer vers la même note Anki ; aucune modification de la carte n’est nécessaire.
