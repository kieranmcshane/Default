# Consignes pour les agents (Codex, Claude)

Lire `README.md` avant toute modification : objectif, règles de rang et sources.

- Travailler sur une branche `codex/<sujet>` ou `claude/<sujet>`, jamais sur `main`.
- Pousser souvent ; fusionner uniquement par pull request.
- Ne compter que les rangs A et B ; ne jamais supprimer de carte pour cause de rang C.
- Ne jamais présenter comme vérifié ce qui n'a pas été vérifié contre une édition
  identifiée ; ne jamais inventer de numéro d'item.
- Chaque vérification doit laisser une trace qu'un humain peut refaire.
